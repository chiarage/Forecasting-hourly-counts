# Forecasting Hourly Counts 🚶 
A Streaming Data Management Time Series Analysis Project done in R, analyzing pedestrian counts from 2015 to 2019 to build 3 different models able to forecast counts for the first two months of 2020.

## File Structure 👈
The project uses the dataset student_dataset.csv and can be run all together in R.
Here are present:
|- student_dataset.csv
|- Genuardi858423_SDMTSA.Rmd
|- Genuardi858423_SDMTSA.pdf 
|- 858423_20260915.csv
where the pdf is the knit of the markdown and 858423_20260915.csv are the obtained results from the forecasting.

## How to Use the Project 🔍
Here is presented the pdf which already contains all the project run for inspection.
For reproducibility one can:
1. Downloading dataset and project: student_dataset.csv and Genuardi858423_SDMTSA.Rmd
2. Open .Rmd file in R and run it.
